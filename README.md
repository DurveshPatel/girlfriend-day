# ❤️ Happy Girlfriend's Day Website

A beautiful and interactive **Happy Girlfriend's Day** website made with **HTML, CSS, and JavaScript**.

This project is designed as a romantic surprise featuring animations, music, a love letter, a timeline of memories, a photo gallery, a live love counter, and a special surprise message.

---

# 🌸 Features

* ❤️ Animated Loading Screen
* 🌹 Romantic Hero Section
* 💌 Typing Love Letter
* 📖 Beautiful Timeline
* 📸 Responsive Photo Gallery
* 💕 Reasons I Love You
* ⏳ Live Love Counter
* 🎵 Background Music
* 🎉 Confetti Celebration
* 💖 Surprise Popup
* 🌸 Floating Hearts Animation
* 📱 Fully Responsive Design

# ❤️ Change the Love Counter Date

Open:

```
script.js
```

Find:

```javascript
const loveDate = new Date("2025-03-01T00:00:00");
```

Replace the date with the day your relationship started.

Example:

```javascript
const loveDate = new Date("2026-02-14T00:00:00");
```

# ▶️ How to Run

1. Download or clone the project.
2. Add your images to the **images** folder.
3. Add your song to the **music** folder.
4. Open **index.html** in any modern web browser.

No installation is required.
